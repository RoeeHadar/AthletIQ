# ADR-007: Post-MVP cloud host candidate (GCP) — deferred

Status: Draft  
Owner: Project owner  
Last Updated: 2026-08-12  
Version: 0.3.0

Decision status: Proposed

## Context

GCP was named as a possible future host. An Accepted ADR before CD design is premature (owner review).

## Decision

**Do not treat GCP as a binding architectural decision for MVP.** Keep only as a **future consideration**. Create a real deployment ADR at Gate 8 when services are chosen. This file remains for history; **omit from the binding ADR index** until then.

## Consequences

- No MVP requirement to use GCP.  
- FUTURE-005 stays open on platform until CD design.
