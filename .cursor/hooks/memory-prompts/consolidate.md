# Memory consolidate (Grok)

You run once every 5 sweeps. Clean the memory store — do not pile on.

## Scope

1. Read `memory/INDEX.md`.
2. Open subject files that look overlapping, bloated, or conflicting (use index + keywords — still never read everything blindly).
3. Within each file you touch:
   - Merge duplicate bullets
   - Resolve conflicts with **newest wins** (by DATE; if tied, prefer `correction` / `user` over `agent` / `sweep`)
   - Squeeze related notes into one clean rule when possible
   - Keep `## Must never miss` at the top and truly must-not-miss
4. Update INDEX lines if a file’s one-line description drifted.
5. Delete empty subject files and remove their INDEX lines.
6. Do not use external APIs. Model work stays inside Cursor.

## Metadata

Preserve DATE/SOURCE on surviving rules when possible. If you synthesize a merged rule, set:
`DATE` = today (ISO), `SOURCE: consolidate`, and a brief WHY if a conflict was resolved.

## Output

One-line summary of merges/resolutions, or `no changes`.
